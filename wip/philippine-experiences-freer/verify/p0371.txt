# List of Spanish and Philippine Terms Used in This Volume

Many of the words marked T are used generally throughout the Islands.

(<i>T.—Tagalog; B.—Bicol; I.—Igorrote; M.—Moro; G.—Gaddan</i>)

| abacá | Manila hemp |
| abeja | bee |
| Adios | good-by |
| administrador | administrator; in this use, an ecclesiastic temporarily filling the office of bishop |
| alcalde | mayor—under the Spanish régime |
| alegria | joy |
| almacén | warehouse |
| almacenero | warehouse-man |
| ambos | both |
| Americano | American |
| anito (T.) | spirit |
| anting-anting (T.) | a magic charm |
| arroz | rice |
| aspirante | aspirant |

| bache | mud-hole |
| baguío (T.) | typhoon |
| baile | ball, dance |
| bailarina | belle at a ball |
| banca (T.) | a dug-out canoe |
| banquete | banquet |
| bandillo | proclamation by town-crier |
| barong (M.) | warrior’s broad and heavy knife |
| baroto (T.) | a dug-out canoe, larger and heavier than a <i>banca</i> |
| barrio | ward, outlying hamlet |
| bejuco | rattan |
| betel | a vine and its leaf |
