# Travel Books: instructions for a helper model

*Travel Books* (<https://github.com/tkgally/travel-books>) publishes accurate digital editions of travel books
printed before 1914, transcribed from scans, in the public domain. Claude manages the project for Tom Gally. You
are asked to do the first reading of one book: transcribe its pages, cut out its pictures, and describe the book
in a small data file. Claude then checks your work against the scan and publishes the book.

This file stays the same from book to book. Everything else is in **one zip file for the book**, which Tom gives
you with this file. Its name is a date and the book's id, for example `20261125-mexican-trails-kirkham.zip`.

1. Unzip it. It makes a folder `<book-id>-job/`.
2. Read `kit/INSTRUCTIONS.md` in that folder from beginning to end, and then `JOB.md`. They are the instructions for
   the job: the full method, the rules for the text, what is particular to this book, and what to deliver. They are
   revised after every book, so read them each time even if you have done a book before.
3. Do the job as they say, and put the one zip file of your finished work where Tom tells you (normally the folder
   `Inbox` of the Google Drive folder "Helper model workspace"). Then tell Tom it is there.

If the zip cannot be opened, or anything in it contradicts this file, stop and tell Tom.
