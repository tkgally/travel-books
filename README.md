# Travel Books

First-person travel books written in English and published before 1914, transcribed from scans at the
Internet Archive and published as web pages, EPUB, ODT and JSON.

Site: https://tkgally.github.io/travel-books/

The books are chosen, transcribed and checked by Claude models; the method is in `notes/workflow.md` and is
described for readers on the site's About page. Errors can be reported in the issues.

- `books/` — the source of each published book (page text, metadata, illustrations)
- `tools/`, `prompts/`, `tests/` — the pipeline
- `site/` — stylesheets and the site's own pages
- `notes/` — working notes
- `CLAUDE.md`, `RESUME.md` — instructions for the sessions that do the work

Everything here is dedicated to the public domain (CC0 1.0); see `LICENSE`.
